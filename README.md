# 拾知 · 工商管理结构化学习

面向零基础学习者、适配安卓手机的中文离线 PWA。React、TypeScript、Vite、IndexedDB；1424 道候选题、11 个**旧版章节**。全部答案、解析、来源与核验标记来自原题 JSON，未修改原始资料，也未映射为 2026 考纲。

请先阅读 [原题库说明](README_请先阅读.md)。题库、知识资料和解析均待人工核验；结构通过不代表内容准确。

## 新版从哪里开始

首次打开默认进入 **学习**，先认识企业全景，再沿六个经营问题建立知识结构。默认优先学习 20 个入门核心，也可切换到全部 48 个专题；它们是学习编排，不是 2026 考纲优先级。

每个专题使用固定五步：**现实问题 → 少量概念 → 示例推演 → 闭卷回忆 → 理解检验与间隔复习**。回忆先写再对照，文字不自动判分；本轮最多三道检验题必须在本次回忆后作答，完成后才安排下次复习。学习步骤、回忆文本、轮次与提醒时间随 JSON 备份保存，旧版备份仍可导入。到期提示只在打开应用时显示。

**题库** 提供 860 道章节习题和 564 道资料标注历年题两个入口。历年题按 2021—2025 年的 7 个年份/场次组合展示，题数不齐，不能作为完整原卷；各入口可筛题型，单章可继续拆到专题和原题考点。

**知识手册** 以 48 个提炼专题为主体，原始文档保留在可展开的追溯区。每个专题有关键要点、易混边界、自测、关联练习与出处。题目可跳回专题，错题按专题汇总，可执行“补知识 → 同类题 → 历年题”的复习流程。关联采用同章原始考点标签的关键词，尚未人工逐题核验；未匹配的题明确保留为待细分，不强行归类。

设计原理、具体间隔规则、局限与研究参考见 [学习设计说明](docs/learning-design.md)。页面完成度与最近答对率均不代表长期掌握。

## 本地开发

需要 Node.js 22.12+（推荐 24）和 npm。

```sh
npm ci
npm run dev
```

开发服务器默认端口 5173。开发模式用于编写代码，**离线功能须在生产构建下验证**：

```sh
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

浏览器自动化测试（另一个终端，先停止上述预览服务器，测试会自己启动）：

```sh
# 若机器没有 /usr/bin/chromium，先安装 Playwright 浏览器：
npx playwright install chromium
npm run test:e2e
```

可以通过 `CHROMIUM_PATH` 指定已有 Chromium。测试以 Pixel 7 的视口和触摸设置运行，验证错题回练、章节续练、IndexedDB、JSON 导出恢复、案例表格、多选判分、离线关闭页面后重新打开、两份知识手册和窄屏溢出。它不代替安卓真机安装测试。

## 手机上下一步点击哪里

安卓安装需要 **HTTPS 网站**；仅有仓库代码或本机开发服务器不能直接安装到手机。仓库带有**手动触发**的 GitHub Pages 部署流程，不会在提交时自动发布。

1. 将本次代码提交推送到 GitHub 仓库。
2. 确认资料可用于该静态网站。网站上的题库通常可被网址访问者读取。
3. GitHub 仓库 → **Settings → Pages → Build and deployment → Source → GitHub Actions**。
4. **Actions → Deploy study PWA → Run workflow → Run workflow**。成功后点击 `deploy` 任务中的网站地址。若 Pages 不可用，请检查仓库可见性、账号套餐和组织权限，或将 `dist/` 部署到有权限的 HTTPS 静态托管平台。
5. 安卓 Chrome 打开该 HTTPS 地址 → 底部 **我的** → 等待 **离线资源已就绪** → 点 **安装到手机**（若提供），或 Chrome 右上角 **⋮ → 添加到主屏幕 / 安装应用**。
6. 桌面打开应用 → **学习 → 开始引导学习**；直接练题可进入 **题库 → 章节习题 / 历年真题**。断网后可继续使用已缓存的完整题库和知识手册。

构建使用相对资源路径，可部署于仓库子路径。离线资源约 2MB，首次加载需联网完成缓存。资料更新时会出现更新按钮；确认后重新加载，学习记录保留。

## 更新已经发布的网站

将更新提交推送并合并至 `main` 后，在 **Actions → Deploy study PWA → Run workflow** 选择 `main` 运行。部署成功后，联网重新打开原网站，出现新版提示时点 **更新应用**；若浏览器仍在旧页面，关闭后重新打开或刷新，再等待更新提示。

更新沿用原 IndexedDB 名称与题目 ID，不清除已有作答和错题记录；恢复旧版 JSON 时，引导学习记录为空但原作答、备注与章节游标仍可使用。更新前可在 **我的** 中导出一份备份。不要通过清除浏览器数据来刷新应用，否则本机记录可能丢失。

## 练习与数据规则

- 章节习题、历年题分开显示，支持来源、题型、知识专题及原题考点筛选；各练习范围位置分别保存。
- 提交后显示原资料答案、解析；多选按集合完全匹配判对，不模拟正式考试部分得分。
- 案例背景支持 Markdown 表格；只在显示时转换提取数据中的 `\\n`，不改原 JSON。
- 错题本按最近一次作答是否错误收录，再次答对自动移出，练习次数保留。
- 学习进度按练过的唯一题目计数；正确率按各题最近一次作答计算。
- 每道题可展开来源文件、行号、题目 ID、年份/场次和待核验状态，保存本地纠错备注。
- 两份原始知识资料均可离线阅读。解析保留原文，可能包含来源残留，使用时请核对。
- **我的 → 导出 JSON 备份**：保存作答记录、各练习范围的位置、引导步骤、回忆文本、复习安排和纠错备注。**选择备份恢复**会先校验版本、题目 ID、选项、判分与章节；显示确认后整体替换本机记录，建议先备份当前记录。此功能不导入或修改题库。
- 本机存储失败会明确提示；浏览器数据被清理、更换域名/设备后需要手动恢复备份。建议定期导出，不要将浏览器存储作为唯一备份。

没有账号、云同步、远程字体、统计上报或 API 密钥。题库随应用打包；IndexedDB 存储只属于当前网址和浏览器。安装和服务进程不会自动跨机器保留。

## 文件

- `src/App.tsx`：练习、错题、知识手册、备份和安装界面。
- `src/GuidedLearning.tsx`、`src/course.ts`：新手五步学习流程与间隔复习规则。
- `src/curriculum.json`、`src/lesson-examples.json`：提炼后的知识卡和独立教学示例。
- `src/learning.ts`、`src/practice.ts`：知识关联、分来源题库和各练习范围。
- `src/storage.ts`：IndexedDB、判分记录及备份校验。
- `vite.config.ts`：PWA 安装清单与完整离线预缓存。
- `tests/`：数据/存储测试和移动浏览器端到端测试。

本仓库没有提供题目答案的正确性保证。旧版第十章“电子商务”保持旧版名称，不宣称符合 2026 考纲。公开部署需由资料使用者确认权限。
